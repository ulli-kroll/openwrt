1. Update the FEM params in bdwlan.txt file 
2. Run command "custom_fem_rx_glut_v2.exe <bdwlan.txt> <chip_name>"
3. rxgainlut.bin will get generated in the current directory for the band supported in bdwlan.txt

Commands :
 For Waikiki:  custom_fem_rx_glut_v2.exe bdwlan.txt qcn9224
 For Miami: custom_fem_rx_glut_v2.exe bdwlan.txt ipq5332
